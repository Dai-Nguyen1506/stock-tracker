# Project Documentation

Welcome to the project documentation for the High-Performance Crypto/Stock Tracker & AI Assistant.
We have split the information into several focused areas to make it easier to read and maintain:

- [Architecture Overview](architecture.md) - System architecture diagram and directory structure.
- [Database Layer](database.md) - Details on Cassandra, PostgreSQL, Redis, and ChromaDB usage, schema, and optimizations.
- [Core Components](components.md) - Deep dive into backend ingestion workers and API routers.
- [Frontend](frontend.md) - Overview of the React/Vite UI components.
- [Performance Benchmarks](benchmarks.md) - Comparative analysis of Cassandra vs PostgreSQL read/write speeds.
- [Runbook](runbook.md) - Instructions for running and monitoring the system via Docker Compose.
